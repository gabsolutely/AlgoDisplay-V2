Example: Bubble Sort (JavaScript)

for (let i = 0; i < arr.length - 1; i++) {
  for (let j = 0; j < arr.length - i - 1; j++) {
    await compare(j, j + 1);
    if (arr[j] > arr[j + 1]) {
      await swap(arr, j, j + 1);
    }
  }
}

Graph Controls & Interaction

- Left-Click node: Set Start Node (marked in green with 'S' badge)
- Right-Click or Shift+Click node: Set Target Node (marked in red with 'T' badge)
- Drag node: Freely reposition any node across the canvas
- New Graph: Generates an organic force-directed layout
- Presets: Random Graph, Binary Tree, Directed DAG, Negative Weights

Example: Graph BFS

const start = getStartNode();
const target = getTargetNode();
const queue = [start.id];
const visited = new Set([start.id]);
const parent = {};

while (queue.length > 0) {
  const cur = queue.shift();
  await visitNode(cur, "visiting");
  if (cur === target.id) {
    const path = []; let c = cur;
    while (c !== undefined) { path.unshift(c); c = parent[c]; }
    await markPath(path); return;
  }
  for (const n of getNeighbors(cur)) {
    if (!visited.has(n.id)) {
      visited.add(n.id); parent[n.id] = cur;
      queue.push(n.id);
    }
  }
}

Grid Terrain & Values Guide

- 'S' Badge: Start Cell (drag to move)
- 'T' Badge: Target Cell (drag to move)
- Dark Slate Cells: Impassable Walls (click/drag to draw or erase)
- Grass '*2': Terrain movement weight multiplier = 2x
- Sand '*4': Terrain movement weight multiplier = 4x
- Mud '*8': Terrain movement weight multiplier = 8x
- Dijkstra and A* pathfinding route around mud and sand to minimize total cost.
- Unweighted BFS treats all open cells as equal cost (1).

Grid API (JavaScript)

const start = getStartCell()           // { row, col }
const target = getTargetCell()         // { row, col }
const nbrs = getGridNeighbors(r, c)    // Array of [{ row, col, weight, terrain }]

await visitGridCell(r, c, "visiting")  // Wavefront exploration (amber glow)
await visitGridCell(r, c, "path")      // Instantly highlights cell on final path (green)
log("message")                         // Output to execution log

Architecture Overview

AlgoStudio is a single-page vanilla JS/HTML/CSS app. No build step needed.

  • index.html — All markup and toolbar controls
  • style.css — Theme variables + layout (dark/light/colorblind)
  • js/core.js — Main AlgorithmVisualizer controller class
  • js/graph-engine.js — Graph & grid data structures
  • js/graph-renderer.js — SVG graph renderer
  • js/grid-renderer.js — Canvas grid renderer
  • js/array-renderer.js — Bar chart renderer
  • js/pseudocode-manager.js — Pseudocode text + line highlighting
  • js/sound-manager.js — Web Audio API synthesis
  • js/python-runner.js — Pyodide WASM Python runner

Adding a New Algorithm

To add a new sorting/searching algorithm:

  1. Add an option to <select id="algorithm-select"> in index.html
  2. Add the JS template in setExampleCode() in core.js
  3. Add pseudocode lines in pseudocode-manager.js
  4. Add complexity info in getTheoreticalComplexity() in core.js
  5. Add pseudocode line mapping in getOpLineNumber() in core.js

  }
}
